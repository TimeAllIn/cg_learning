湖南工业大学计算机图形学课程设计项目

版本记录：

V1.0  支持程序输出OBJ文件，且文件可以以cgLearn格式或者cgGame格式保存
 
  V1.1  优化部分代码，丰富界面ui
  
  V1.2  用户可以添加背景图片，也可以播放音频，可以调整音频的音量大小和音高高低
  
  V1.3  游戏模式的建立，用户导入cgGame文件，可以进入程序的游戏模式。支持背景图片的重加载

V2.0  优化了旧版本的UI，重写了部分代码。废除了游戏模式
  
  V2.1  支持协作模式，用户可以多人协作共同完成建模。
  
  V2.1.1  优化代码，减小的程序的大小

  V2.1.2 优化多人协作模式
  
  V2.2.1 增加自定义颜色
